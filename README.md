# CAPS CLUB AXM

Landing page / ecommerce para **CAPS CLUB AXM** — compra y venta de gorras al por mayor y al detal en Armenia, Quindío, Colombia.

## Desarrollo local

```bash
npm install
npm start
```

Abre `http://localhost:5315`.

## Regenerar imágenes

Las imágenes se generan a partir del material real del cliente (`C:\Users\Lenovo\Desktop\capsclub\logo.png` y `gorras.png`):

```bash
npm run build:img
```
